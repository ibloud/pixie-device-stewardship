## Audit and maintenance

link-audit.json records automated GET response checks of 60 distinct resource URLs, including the separately checked Brussels directory. Redirects were followed. Results describe availability from this execution environment, not Googlebot access, service quality, login safety or iPad compatibility.

Statuses: response-ok, redirected-response-ok, not-found, manual-review (403), retry-needed (timeouts or transient errors). Recheck 404s and retry transient failures before proposing removal upstream. A 200 response can still be a parked domain or application error. Manual review remains necessary. The embedded-code notebook's URL is long and needs manual review even if its host responds.

The initial targeted requests returned 200 for AT Protocol, Smoke Signal, WhiteWind and Streamplace; 403 for PDSls, Linkat and Standard.site; and 502 for Brussels. The broader audit sometimes differed (for example WhiteWind timed out), so these are observations, not permanent working/broken claims.

blueprints.at/awesome-atproto was reported by the owner to open the GitHub code page in the GitHub app, not a standalone published directory. Do not offer it as a separate launch experience.
