Rules-fit determination

File stewardship does not conflict with the hackathon.

It is the user problem. The compliance question is whether the new submission is a working Amazon-track application rather than a pre-existing documentation project.

Fits

  • Alexa+ permits a working Agent Skill or self-hosted MCP server.
  • An optional web simulation may demonstrate the Alexa+ experience.
  • The open-source mini challenge aligns with PIXIE's public repository and licenses.
  • The project addresses a specific customer need and a credible audience.

Must be controlled

  • Document every significant feature built after August 31.
  • Show runtime behavior in code and in the video—not only in documentation.
  • Use synthetic files in public tests and demos.
  • Do not include unlicensed media, trademarks, private correspondence, or health records.
  • Keep the project freely testable through the judging period.

Decision: proceed with Alexa+ and the Open Source mini challenge. Keep the Artist File Protocol as the domain model, implement one reversible file-intent workflow, and maintain a dated change ledger separating pre-hackathon materials from competition work.
