# Security Policy

## Current scope

This repository currently contains documentation and research specifications, not a production service. Do not submit real participant records, private media, credentials, access tokens, health information, or unpublished security details through public issues.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting feature when available. If it is not available, open a public issue containing only a minimal notice that a private security report is needed. Do not disclose exploitation steps or affected personal data publicly.

## Maintainer response

Maintainers will acknowledge when practical, assess scope, restrict exposed data, document remediation, and publish a non-identifying advisory when disclosure is safe.
